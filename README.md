# Sitesh Kumar Dash — Mad Scientist Lab

Compact personal portfolio: biochemistry, molecular biology, Remac-PET research, and science facilitation.

## Run locally

Open `index.html` in a browser, or serve the folder:

```powershell
cd "C:\Users\Sitesh Kumar Dash\Projects\sitesh-dash-lab"
python -m http.server 8080
```

Then visit http://localhost:8080

## Deploy

Upload the folder to GitHub Pages, Netlify, or Vercel (static site—no build step).
